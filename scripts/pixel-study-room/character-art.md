# 캐릭터 v5 제작 기록

24 × 32 SVG 인형을 동작별 원화 프레임으로 교체했다. 배경·가구·조명·지도·체크인 규칙은 유지한다.
Codex pet의 [원화와 상태별 스프라이트 제작 방식](https://github.com/openai/skills/tree/main/skills/.curated/hatch-pet)을 참고했고,
Codex의 캐릭터나 런타임을 복사하지 않고 크루 다섯 명을 새로 제작했다.

## 결과물

`src/assets/pixel-characters/{sh,wg,th,jj,kj}-v5.webp`

각 파일은 1152 × 2688, 6열 × 12행이며 한 프레임은 192 × 224이다.
캐릭터는 약 160px 높이로 등록되어 이전 32px보다 작은 표정과 옷·머리카락 묘사가 선명하다.
캐릭터당 72프레임, 총 360프레임이다. 왼쪽 방향은 오른쪽 프레임을 반전해 표시한다.

| 크루 | 외형 | 공부 / 휴식 |
| --- | --- | --- |
| 승환 | 검은 짧은 머리, 노란 후드 | 필기 / 기지개 |
| 웅 | 헝클어진 검은 머리, 초록 카디건 | 독서 / 차 |
| 태현 | 옆가르마, 안경, 파란 셔츠·멜빵 | 타이핑 / 독서 |
| 진주 | 양쪽 머리 묶음, 주황 카디건 | 필기 / 손인사 |
| 경진 | 긴 머리, 분홍 머리핀, 보라 상의 | 독서 / 차 |

행 순서: 눈 맞추기, 옆으로 걷기, 앞으로 걷기, 뒤로 걷기, 독서, 차 마시기, 대화,
물 주기, 개인 공부, 서가에서 책 고르기, 커피 내리기, 기지개·손인사.
눈 깜빡임과 차 마시기에는 쉬는 구간을 두고, 멤버마다 재생 시점을 조금씩 어긋나게 했다.

## 생성 및 패킹

**내장 `image_gen` 사용.** 원본 캐릭터 → 같은 인물을 참조한 48프레임 시트 → 24프레임 추가 행동 시트.
걷기는 18프레임 시트를 별도로 보강해 교체했다. 넓게 디딤 → 발 모음 → 무릎 통과 → 반대 발 디딤이
눈에 구분되도록 만들어 처음 시안의 미끄러지는 자세를 줄였다.
[프롬프트 세트](character-prompts.json)와 [보행 보강 프롬프트](character-walk-prompts.json)에 공통 지시와 인물별 지시를 보관한다.
생성 원본은 Codex의 `generated_images`에 유지하고, 앱은 저장소 안의 최종 WebP만 사용한다.

`pack-characters.mjs`는 원화의 연결된 실루엣을 찾아 프레임을 추출한다.
원본에 실제 알파가 있으면 보존하며, 불투명 체크 무늬로 출력된 시트는 연결된 중성색 외곽 매트를 분리한다.
신발·눈·책의 흰색은 닫힌 윤곽선 안에 보존한다. 이미지 전체를 다시 그리는 보정은 하지 않는다.
한 시트는 같은 비율로 변환하고 발바닥을 y=204에 맞춘다. 물줄기처럼 넓은 소품은 행 전체를
같이 이동해 잘림과 프레임별 좌우 흔들림을 피한다. 각 인물의 `*-atlas.json`에 등록 결과를 기록했다.

WebP 품질 92, 알파 품질 100으로 출력한다. 다섯 파일 합계 약 2.6MB이며 브라우저가 같은 파일을
지도·프로필·확대 보기에서 재사용한다. 이미지 처리용 `sharp`는 로컬 제작 도구이고 앱 런타임 의존성을 추가하지 않는다.

```sh
# sharp가 설치된 로컬 제작 환경에서, 선택한 원본 PNG 경로를 전달한다.
node scripts/pixel-study-room/pack-characters.mjs sh base.png actions.png walk.png
```

## 재생과 검증

`pixelCharacter.ts`가 행동을 프레임 행으로 연결하고, `PixelCharacter.tsx`가 SVG 창 안에서 시트를 표시한다.
CSS의 단계 재생으로 매 프레임 React 렌더를 발생시키지 않는다. 동작 변경 때만 해당 행의 재생을 시작하고,
지도 확대·선택·분위기 변경은 현재 재생을 유지한다. 정지는 프레임도 그대로 멈추고, 탭을 숨기면 함께 멈춘다.
OS 동작 줄이기는 정지 화면을 사용한다. 이동 중에는 소품을 내려놓고 방향에 맞는 걷기 프레임을 쓴다.

독립 시연의 ‘작은 표정까지, 가까이.’에서 같은 원화를 확대해 모든 동작과 걷는 방향을 확인할 수 있다.
미리보기 조작은 공부 상태를 바꾸지 않는다.

[걷기 애니메이션 GIF](characters-walk.gif)는 최종 다섯 시트의 보행 프레임을 순서대로 재생한다.

`check-characters.js`: 브라우저가 디코딩한 실제 360프레임의 내용·알파, 여섯 걷기 프레임의 재생,
모든 동작과 방향, 프레임 정지·재개, 정지 중 체크인, 분위기·지도 변경 중 재생 유지를 검사한다.
