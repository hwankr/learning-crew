# 픽셀 도서관 시연

브랜치: `feat/pixel-study-room`

```sh
npm run dev -- --host 0.0.0.0 --port 5173
```

- 시연: <http://localhost:5173/?pixel-demo=1>
- **자동 시연**: 다섯 크루가 차례로 입장하고 승환이 공부를 마치는 약 18초의 장면.
- 각 멤버의 **공부 시작 / 공부 종료**: 정원 ↔ 도서관 이동. 이동 중에 다시 눌러도 새 목적지로 이어진다.
- **모두 도서관으로 / 모두 쉬어가기**: 다섯 명 동시 이동. 이미 공부하던 멤버의 시작 시각은 유지한다.
- **움직임 끄기**: 이동과 반복 동작을 끄고 현재 공부 상태의 위치를 바로 표시한다.
- 모바일에서는 장면이 화면 상단에 머물러 크루 버튼을 조작하며 움직임을 볼 수 있다.

시연 상태는 메모리에만 존재하며 새로고침하면 초기 상태로 돌아간다. `main.tsx`에서
설정·로그인·IndexedDB·서비스 워커 등록·동기화 초기화보다 먼저 분기하므로, 로그인 토큰이
저장된 브라우저에서도 시연 조작이 실제 기록이나 알림을 만들지 않는다.

## 기존 앱과 연결

`CrewPanel`의 체크인 바로 아래에도 같은 `PixelStudyRoom`을 넣었다.
로그인 정보가 없는 개발 브라우저에서 `/?user=승환`으로 기존 앱 데모에 들어간 다음,
모바일 **홈** 또는 데스크톱 **크루 패널**의 도서관 버튼으로 연결을 확인할 수 있다.

- `MemberStatus`를 읽기만 한다. 서버 API, 스키마, 공부 기록 저장 로직은 바꾸지 않았다.
- `isStatusActive`를 재사용해 기존 보드와 동일하게 14시간 만료를 적용한다.
- 도서관에서 공부하는 멤버만 책상에 앉는다. 집·카페·기타에서 공부하면 장면 밖으로
  이동하고, 아래에 실제 장소를 표시한다.
- 기존 앱의 다른 기기 상태 반영은 원래의 20초 폴링을 따른다.
- 좌석은 멤버 순서에 고정돼 입장·퇴장 순서 때문에 다른 사람의 자리가 바뀌지 않는다.
- 첫 렌더와 화면 재진입에서는 현재 위치를 곧바로 보여주며 입장을 다시 재생하지 않는다.
- 이동은 브라우저 애니메이션으로 처리한다. 이전 동작을 취소할 때 화면상의 좌표를
  이어받으며, 취소된 콜백과 자동 시연 타이머는 정리한다.
- OS의 `prefers-reduced-motion` 설정과 탭 숨김 상태에서도 반복 애니메이션을 끈다.
- 픽셀 캐릭터와 배경은 프로젝트에서 그린 SVG이며 추가 런타임 패키지는 없다.

## 검증

2026-09-10 기준:

- `npm run build`: 타입 검사 3종과 프로덕션 빌드 통과.
- `npm test`: 42개 파일, 736개 테스트 통과. 새 상태·경로·렌더링 회귀 테스트 13개 포함.
- Chrome 실제 브라우저: 시작/종료, 이동 중 반전, 다섯 명 동시 이동과 좌석 분리,
  동작 중 움직임 끄기/켜기, 숨김/복귀, 수동 조작 시 자동 시연 취소 통과.
- 동작 줄이기: 공부 상태는 바뀌고 모든 장면 애니메이션은 0개인 것을 확인.
- 1440px 데스크톱, 390px 모바일 시각 확인. 320px 가로 넘침 없음.
- 390px에서 마지막 크루 버튼을 누를 때도 장면이 화면에 남아 있는 것을 확인.
- 유효한 멤버 접두사의 테스트 토큰을 미리 저장한 상태에서 시연 재진입:
  토큰 유지, API 요청 0건, IndexedDB 데이터베이스 0개, 서비스 워커 등록 0개 확인.
- 기존 앱 데모에서 도서관 체크인 → 이동/인원 반영 → 종료 → 집 체크인 시 장면 밖 이동과
  크루 보드의 장소 일치 → 도서관 복귀 → 피드/홈 재진입 시 입장 재생 없음 확인.

화면: [데스크톱](desktop.png) · [모바일](mobile.png) · [기존 앱 연결](integrated-mobile.png).

실제 브라우저의 주요 이동 회귀 검증을 다시 실행하려면:

```sh
npx agent-browser open 'http://localhost:5173/?pixel-demo=1'
npx agent-browser eval --stdin < scripts/pixel-study-room/check-browser.js
```

새로 연 시연 화면에서 OS의 동작 줄이기를 끈 상태로 실행한다. 테스트는 약 20초 걸린다.
움직임 줄이기 설정은 별도로 켜서 시작/종료 시 즉시 이동하고 애니메이션이 멈추는지 확인한다.
