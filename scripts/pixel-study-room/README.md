# 숲속 캠퍼스 시연

브랜치: `feat/pixel-study-room`

```sh
npm run dev -- --host 0.0.0.0 --port 5173
```

시연: <http://localhost:5173/?pixel-demo=1>

## 기존 테마와 화면 구조 유지

- 앱의 흰 배경, 노란 강조색, 글자·간격, 아바타와 장소 이모지는 변경 전 그대로다.
  `src/styles.css`, `icons.tsx`, `StatusBar.tsx`는 `66fba35`와 동일하다.
- 체크인 → 공부 공간 → 다가오는 일정 → 오늘의 크루 → 이번 달의 원래 순서를 유지한다.
  체크인과 크루 목록을 묶던 바깥 카드와 그림자를 제거했고, 지도만 독립된 화면으로 놓았다.
  시연 페이지도 흰 배경과 열린 배치를 사용한다. 픽셀 UI 색상은 해당 컴포넌트에만 적용된다.
- 고급 캐릭터 원화, 이동·공부·자율 행동, 지도 확대·이동과 반응형 동작은 유지한다.
  크루 아바타를 누르면 지도와 상세 상태가 바뀌며, 선택은 공부 기록에 영향을 주지 않는다.
  `공간 설정`과 `크루를 조금 더 가까이`는 필요할 때 펼친다.

[시연 데스크톱](theme-restored-demo-desktop.png) · [시연 모바일](theme-restored-demo-mobile.png).

홈·피드·캘린더·통계 이동을 확인했다. 브라우저 오류와 가로 넘침은 없었다.
`cohesion-*` 파일은 흰 테마를 복원하기 전 시안의 기록이며 현재 화면이 아니다.

`check-integration.js`는 토큰 없는 `/?user=승환` 앱 데모의 크루 패널을 연 상태에서 실행한다.
승환의 공부를 종료한 초기 상태에서 시작하며, 흰 배경과 원래 섹션 순서,
체크인·선택·공간 설정을 실제 UI로 검사한다.

## 화면 크기에 따른 배치

독립 시연은 자주 쓰는 체크인을 지도 가까이에 두고, 캐릭터 확대 미리보기는 아래로 옮겼다.

| 화면 | 배치 |
| --- | --- |
| 데스크톱 · 1100px 이상 | 캠퍼스와 280–300px 크루 목록을 나란히 표시한다. |
| 태블릿 · 681–1099px | 선택한 크루 체크인 → 캠퍼스 → 2열 크루 목록 순서로 표시한다. |
| 모바일 · 680px 이하 | 선택한 크루 체크인 → 높이를 제한한 지도 → 세로 크루 목록 순서로 표시한다. |

- 모바일 상단의 크루 선택과 공부 시작·종료는 지도 선택 및 크루 카드와 같은 상태를 사용한다.
- 지도와 캐릭터를 하나만 렌더링한다. 시연의 열 배치가 바뀌어도 진행 중인 이동과 체크인이 유지된다.
- 지도 높이와 도구 배치는 `campus` 컨테이너의 실제 너비를 따른다. 가로로 낮은 화면에서는
  화면 높이에도 맞춰 줄인다. 기본 확대율은 캐릭터를 알아볼 수 있는 크기를 유지하며,
  사용자가 직접 고른 확대율은 창 크기를 바꿔도 유지한다. `전체 보기`는 가로·세로를 모두 맞춘다.
- 기존 앱은 홈의 체크인 아래와 데스크톱 크루 사이드바라는 위치를 유지한다.
  사이드바의 지도 높이는 약 230px, 모바일 홈에서는 약 250px이다. 터치 기기에서는
  지도·동작 도구의 버튼 높이를 44px로 늘린다. 기존 앱 셸의 전환 기준은 900px이다.

모바일 크루 선택·체크인과 지도 키보드 선택 간 동기화, 동작 줄이기도 확인했다.

데스크톱 296px 패널을 확인했다. 기존 카메라·360프레임 캐릭터 브라우저 검사도 통과했다.

## 이번 버전에서 달라진 점

- **더 세밀한 캐릭터**: 24 × 32 SVG를 인물별 72프레임의 스프라이트로 교체했다.
  약 160px 높이의 원화로 걷기·눈 깜빡임·필기·독서·타이핑·차 마시기·물 주기·손인사를 표현한다.
  원화와 파일 위치, [제작 과정·프롬프트](character-art.md), [걷기 GIF](characters-walk.gif)를 보관했다.
- **같은 숲속 배경**: 나뭇결, 책등, 식물, 수면과 조명은 기존 SVG 장면을 유지한다.
- **1024 × 640 지도**: 이전 640 × 400보다 면적이 2.56배 넓다.
  도서관, 숲속 카페, 연못 산책길, 꽃밭과 만남의 정원을 오갈 수 있다.
- **자동으로 이어지는 일상**: 화면을 열어 두면 스스로 서가에서 책을 고르고, 커피를 내리고
  마시며, 책을 읽거나 꽃밭에 물을 주고 산책한다. 작업을 마치면 자기 자리로 돌아온다.
- **두 사람의 대화**: 두 크루가 정원으로 이동해 마주 선 뒤 번갈아 말한다.
  양쪽이 모두 도착해야 대화를 시작하며, 대화가 끝나면 각자의 일과로 돌아간다.
- **지도 조작**: 확대·축소, 전체 보기, 마우스 드래그, 터치 스크롤, 방향키를 지원한다.
  캐릭터나 크루 카드를 선택하면 상세 정보와 지도 위치를 함께 확인한다.
  `크루 찾기`로 선택한 캐릭터의 현재 위치를 다시 찾을 수 있다.
  모바일과 기존 앱의 작은 패널은 확대된 지도로 시작한다.
- **노을 / 밤 / 비**: 숲·바닥·창문의 팔레트와 달빛·반딧불이·빗방울이 함께 바뀐다.

## 조작

- `크루를 조금 더 가까이`를 펼치면 같은 캐릭터 원화를 확대해 동작과 걷는 방향을 살펴본다.
  이 미리보기는 체크인 상태에 영향을 주지 않고 자체 정지·재개 버튼을 제공한다.
- `자율 행동`: 기본 켜짐. 끄면 현재 체크인에 맞는 자기 자리로 돌아가 머문다.
- `1× / 2×`: 일과와 이동 속도를 바꾼다.
- `움직임 끄기`: 진행 중인 이동, 반복 동작과 일과 시간을 멈춘다.
  다시 켜면 화면에 보이던 지점부터 이어진다. 멈춘 동안 체크인을 바꾸면 새 상태를 즉시 표시한다.
- `공부 시작 / 공부 종료`: 해당 크루의 가상 체크인을 변경한다. 자동 행동보다 우선한다.
- `모두 도서관으로 / 모두 쉬어가기`: 다섯 명을 동시에 이동시킨다.
  이미 공부하던 멤버의 시작 시각은 유지한다.
- `체크인 시연`: 약 18초 동안 다섯 명의 입장과 첫 번째 멤버의 퇴장을 보여준다.
  수동 체크인은 이후에 예약된 시연 단계를 취소한다. 자율 행동과는 별개의 제어다.
- `캐릭터 이야기`는 자동 행동 소식, `체크인 소식`은 직접 바꾼 가상 공부 상태를 표시한다.

자동 행동과 대화는 **캐릭터 연출**이다. 실제 사용자의 발언이나 활동 기록을 생성하지 않는다.
공부 인원과 경과 시간은 실제 체크인 상태를 따르며, 캐릭터가 잠깐 산책하더라도 바뀌지 않는다.

## 상태와 이동

`CrewPanel`은 체크인, 같은 `PixelStudyRoom`과 오늘의 크루 목록을 하나로 연결한다.
토큰이 없는 개발 브라우저에서 `/?user=승환`으로 기존 앱 데모를 열고
모바일 홈 또는 데스크톱 크루 패널의 체크인으로 확인할 수 있다.

- `MemberStatus`를 읽기만 한다. 서버 API·스키마·공부 기록 저장 방식은 유지한다.
- 기존 보드의 `isStatusActive`와 동일한 14시간 만료를 적용한다.
- 도서관 체크인은 자기 공부 좌석을 중심으로 일과를 반복한다.
  집·카페·기타에서 공부하는 멤버는 장면 밖으로 이동하며 실제 장소를 별도로 표시한다.
- 다른 기기 체크인의 반영 주기는 기존 20초 폴링을 따른다.
- `pixelRoom.ts`: 좌석과 활동 위치, 연결된 통로, 최단 경로와 일정한 이동 속도.
- `pixelLife.ts`: 가상 시계, 목적지 예약, 도착 확인, 일과와 두 사람의 대화.
  목적지를 예약해 여러 사람이 같은 작업 위치를 동시에 점유하지 않는다.
- `PixelRoomMember.tsx`: 브라우저 애니메이션으로 이동하며 실제 도착을 일과에 알린다.
  이동 중 새 체크인이 오면 보이는 좌표에서 방향을 바꾼다.
  취소된 애니메이션의 콜백은 최신 작업을 완료시킬 수 없다.
- `PixelMapViewport.tsx`: 실제 월드 좌표와 독립된 확대·화면 이동.
- 첫 렌더에서는 이미 알려진 체크인을 제자리에 표시한다.
  OS 동작 줄이기와 숨겨진 탭에서는 이동·장식·가상 시계를 멈추며,
  탭으로 돌아와도 숨겨진 시간을 한꺼번에 진행하지 않는다.
- 추가 런타임 패키지나 배경 이미지 다운로드가 없다. 새 캐릭터 WebP 다섯 장은 합계 약 2.6MB이며,
  지도·아바타·확대 보기에서 동일 파일을 재사용한다. 서비스 워커의 기존 해시 자산 캐시도 적용된다.
  이전 회화형 WebP 시안과 [제작 기록](art-direction.md)은 자료로 보관하며 현재 장면에서는 사용하지 않는다.

독립 시연은 메모리에만 상태를 보관한다. `main.tsx`에서 설정 조회·로그인·IndexedDB 초기화·
서비스 워커 등록·동기화 시작보다 먼저 분기한다. 새로고침하면 가상 상태가 초기화된다.

브라우저 검증 스크립트는 새로 연 시연 페이지에서 실행한다.
`check-browser.js`는 체크인 이동과 취소·일시정지, `check-atmosphere.js`는 분위기·선택과
18초 체크인 시연을 검사한다. 두 스크립트는 자율 행동을 끄고 수동 이동을 분리해 확인한다.
`check-life.js`는 자율 행동을 켠 기본 상태를 **85초 동안 입력 없이** 관찰해 작업·산책·대화를 검증한다.
`check-life.js`는 긴 브라우저 명령의 시간 제한을 피하도록 관찰을 시작한 즉시 반환하고 결과를 페이지 변수에 저장한다.

```sh
npx agent-browser open 'http://localhost:5173/?pixel-demo=1'
npx agent-browser eval --stdin < scripts/pixel-study-room/check-browser.js
npx agent-browser reload
npx agent-browser eval --stdin < scripts/pixel-study-room/check-atmosphere.js
npx agent-browser reload
npx agent-browser eval --stdin < scripts/pixel-study-room/check-camera.js
npx agent-browser reload
npx agent-browser eval --stdin < scripts/pixel-study-room/check-dialogue-cancel.js
npx agent-browser reload
npx agent-browser eval --stdin < scripts/pixel-study-room/check-life.js
# 약 90초 뒤 확인
npx agent-browser eval 'window.__pixelLifeResult'
```
